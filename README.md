# Alivizo

منصة عربية حديثة لتصميم الفيديوهات الإعلانية بالذكاء الاصطناعي.

## التشغيل

```bash
npm install
npm start
```

ثم افتح http://localhost:3000

## البنية

- `public/` — واجهة الموقع العربية RTL
- `server.js` — خادم Express
- `render.yaml` — إعداد النشر على Render

المشروع مستقل تمامًا عن مشاريع شركة الاتحاد للصرافة.
